# Loomly

แอพ Windows ที่หรี่จอหลักและลดเสียงตามความทึบขณะเลื่อนหน้า พร้อมเลือกโหมดมาตรฐานหรือปรับเอง

ดาวน์โหลด [Loomly.exe](https://github.com/Nanashi1150/Loomly/raw/refs/heads/main/dist/Loomly.exe) แล้วเปิดใช้งานได้ทันที ไม่ต้องติดตั้ง Python

## แนวคิดและเหตุผลในการออกแบบ

Loomly รวมการหรี่จอและลดเสียงไว้ในเครื่องมือเดียว โดยใช้การเลื่อนหน้าเป็นตัวกระตุ้น ภาพและเสียงจะค่อย ๆ ลดลงเมื่อเลื่อนต่อเนื่อง และคืนระดับเดิมเมื่อหยุดเลื่อน ทำให้การปรับทั้งสองอย่างสัมพันธ์กับการใช้งานโดยไม่ต้องปรับแยกทุกครั้ง

Normal มีค่ามาตรฐานสำหรับเริ่มใช้ทันที ส่วน Custom ให้ปรับการหรี่ เวลา เสียง และภาพตามความต้องการ โดยเก็บค่าของผู้ใช้แยกจากค่ามาตรฐาน หน้าตั้งค่าแบ่งเป็นแท็บเพื่อให้เลือกปรับเฉพาะส่วนได้ง่าย และแจกเป็น EXE เพื่อให้ใช้งานบน Windows ได้โดยไม่ต้องติดตั้ง Python

## วิธีใช้

- หมุนล้อเมาส์หรือกดลูกศรขึ้น/ลงทิศเดียวกัน: ค่าเริ่มต้นเริ่มหรี่ครั้งที่ 4 เพิ่มครั้งละ 20% สูงสุด 95%
- คลิกเมาส์กลางใน Chrome/Edge: เมื่อพบเคอร์เซอร์ Scroll ที่รองรับ ขยับขึ้น/ลงเพื่อหรี่ ยิ่งห่างจากจุดเริ่มต้นยิ่งหรี่เร็ว คลิกกลางซ้ำหรือกด Esc เพื่อยกเลิก
- หยุดเลื่อน: หน้าจอและเสียงค่อย ๆ กลับสู่ระดับเดิมตามเวลาที่ตั้ง
- คลิกสามเหลี่ยมมุมซ้ายล่างเพื่อเปิด **ตั้งค่า** คลิกขวาเพื่อพัก/เปิดการหรี่หรือออกจากแอพ กด **F12** เพื่อออก
- สีสามเหลี่ยม: ฟ้า = พร้อมใช้งาน, แดง = กำลังตรวจหรืออยู่ในโหมดเมาส์กลาง, เทา = พัก

## ตั้งค่า

- **Normal** — ค่าตายตัว: พื้นหลังดำ เริ่มหรี่ครั้งที่ 4 เพิ่ม 20% สูงสุด 95% รอ 3 วินาที แล้วคืนความสว่างใน 5 วินาที พร้อมลดเสียงตามความทึบ
- **Custom** — ปรับได้ใน 3 แท็บ: การหรี่ เสียง และภาพพื้นหลัง โดยไม่เปลี่ยนค่า Normal ค่าจากรุ่นเดิมจะอยู่ใน Custom

ตั้งเวลารอก่อนคืนความสว่างและเวลาคืนความสว่างได้แยกกัน (0–60 วินาที) ขนาดภาพปรับได้ 10–200% และความเข้มภาพ 0–100% ปุ่ม **บันทึกและใช้โหมดนี้** บันทึกค่าที่แก้และเลือกโหมดใช้งาน ปุ่ม **ยกเลิก** ไม่เปลี่ยนค่าหรือโหมด

การลดเสียงใช้ระดับเสียงรวมของ Windows ก่อนเริ่มหรี่เป็นฐาน เช่น ระดับลดเสียง 100% และความทึบ 50% จะลดเสียงลงครึ่งหนึ่ง โดยไม่เปลี่ยนสถานะ mute คืนเสียงเมื่อพัก เปิดตั้งค่า หรือออกจากแอพ หากปรับเสียงเอง แอพจะพักการลดเสียงจนจอสว่าง เพื่อให้ค่าที่คุณปรับมีผลก่อน

ค่าตั้งค่าและภาพเก็บใน `data` ข้าง EXE หากย้ายแอพให้ย้ายโฟลเดอร์นี้ไปด้วย และเลือกตำแหน่งที่เขียนไฟล์ได้

## ข้อจำกัด

แอพใช้หน้าต่างโปร่งใสคลุมจอ ไม่ได้ปรับความสว่างฮาร์ดแวร์ และอาจไม่แสดงบนหน้าต่างเต็มจอแบบ exclusive หรือหน้าจอระบบที่มีการป้องกัน โหมดเมาส์กลางตรวจรูปเคอร์เซอร์ ไม่ได้ตรวจว่าเนื้อหาหน้าจอกำลังเลื่อน จึงอาจไม่รองรับบางแอพหรือธีมเคอร์เซอร์

## Build และทดสอบ

ติดตั้ง Python พร้อม Tkinter แล้วรันจากโฟลเดอร์โปรเจกต์:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests\verify_windows.py
```

ไฟล์ที่ได้อยู่ใน `dist/Loomly.exe` ซอร์สอยู่ใน `src/` ชุดทดสอบอยู่ใน `tests/` และค่า build อยู่ใน `Loomly.spec` ต้นแบบเคอร์เซอร์พร้อมใบอนุญาต Chromium อยู่ใน `src/cursor_templates/`

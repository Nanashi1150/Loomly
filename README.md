# Loomly สำหรับ Windows

ดาวน์โหลด [Loomly.exe](https://github.com/Nanashi1150/Loomly/raw/refs/heads/main/dist/Loomly.exe) แล้วเปิดใช้งานได้ทันที หรือ clone repo นี้เพื่อ build และแก้ไขซอร์สโค้ด

เปิด `dist\Loomly.exe` เพื่อใช้งานเวอร์ชันที่มีการปรับขนาดภาพ ไม่ต้องติดตั้ง Python ในเครื่องปลายทาง ปิดแอปเวอร์ชันเก่าก่อนเปิดเวอร์ชันใหม่

- สามเหลี่ยมสีฟ้าขนาด 50 × 50 พิกเซลอยู่มุมซ้ายล่างของจอหลัก ขอบสามเหลี่ยมแนบขอบซ้ายและขอบล่างของจอ
- เมื่อระบบเปิดใช้งาน คลิกเมาส์กลางแล้วสามเหลี่ยมจะเป็นสีแดงทันทีระหว่างตรวจสัญลักษณ์เคอร์เซอร์ หากพบสัญลักษณ์ Scroll ที่รองรับจึงอนุญาตการหรี่ตามระยะเมาส์ หากไม่พบภายในประมาณ 0.8 วินาทีจะกลับเป็นสีฟ้าโดยไม่เพิ่มความมืดจากเมาส์กลาง หากสัญลักษณ์หายระหว่างใช้งานจะหยุดเพิ่มความมืดและออกจากโหมด
- ตัวตรวจใช้รูปเคอร์เซอร์จริงจาก Windows เทียบกับต้นแบบ Scroll ของ Chromium ทั้ง 11 แบบ (รวมทิศต่าง ๆ) รองรับ Chrome/Edge ที่ใช้สัญลักษณ์เหล่านี้ แอปอื่นหรือธีมที่เปลี่ยนรูป Scroll อาจตรวจไม่พบและจะไม่หรี่ด้วยโหมดนี้ ต้นแบบและใบอนุญาตอยู่ใน `src/cursor_templates` และรวมอยู่ใน EXE
- หลังยืนยัน Scroll แล้ว ใช้แนวระนาบที่คลิกเป็นจุดเริ่มต้น ขยับขึ้น/ลงเกิน 15 พิกเซลจะค่อย ๆ หรี่ ยิ่งห่างยิ่งหรี่เร็ว ขยับซ้าย/ขวาอย่างเดียวไม่เพิ่มการหรี่
- ระยะ 200 พิกเซลนอกช่วงเริ่มต้นให้ความเร็วหรี่สูงสุด: ค่าเริ่มต้นเพิ่มความทึบ 20% ต่อวินาที และไม่เกินระดับสูงสุดที่ตั้งไว้ กลับมาใกล้แนวเริ่มต้นจะหยุดเพิ่มความมืด และค่อย ๆ สว่างหลัง 3 วินาที
- คลิกกลางแล้วปล่อยโดยไม่เลื่อนจะเปิดโหมดค้าง คลิกกลางซ้ำ คลิกปุ่มอื่น กด Esc หมุนล้อเมาส์ หรือกดลูกศรขึ้น/ลงเพื่อยกเลิก หากกดกลางค้างแล้วเลื่อน เมื่อปล่อยปุ่มจะยกเลิกโหมด
- โหมดนี้ยืนยันสัญลักษณ์ Scroll แล้วประมาณความเร็วจากตำแหน่งเมาส์ ไม่ได้ตรวจเนื้อหาหน้าจอ จึงอาจยังหรี่เมื่อเลื่อนถึงขอบหน้าแต่แอปยังแสดงสัญลักษณ์ Scroll
- ค่าเริ่มต้น: เลื่อนเมาส์ หรือกดลูกศรขึ้น/ลงทิศเดียวกันครบ 3 ครั้ง ครั้งที่ 4 จะหรี่หน้าจอเพิ่ม 20% สูงสุด 95% แล้วเริ่มนับชุดใหม่
- เปลี่ยนทิศหรือเว้นเกิน 2 วินาทีจะเริ่มนับใหม่
- เมื่อไม่มีการเลื่อนหรือลูกศรขึ้น/ลงเกิน 3 วินาที หน้าจอจะค่อย ๆ สว่างขึ้น
- คลิกสามเหลี่ยมเพื่อเปิดหน้าตั้งค่า ปรับจำนวนครั้งก่อนเริ่มหรี่ (1–100) ระดับที่หรี่เพิ่มแต่ละครั้ง และระดับสูงสุด (1–95%) จากนั้นกด **บันทึก**
- จำนวนครั้งก่อนเริ่มหรี่หมายถึงจำนวนครั้งที่ยังไม่หรี่ เช่น ตั้งไว้ 2 จะเริ่มหรี่ในครั้งที่ 3
- ระหว่างเปิดหน้าตั้งค่า การหรี่จะพักชั่วคราวและหน้าจอสว่างตามปกติ ปิดหน้าตั้งค่าแล้วเริ่มนับใหม่
- ใช้ปุ่ม **นำเข้าภาพ…** เพื่อเลือก PNG, JPG, WebP, BMP, GIF หรือ TIFF มีตัวอย่างภาพก่อนบันทึก ภาพเคลื่อนไหวใช้เฟรมแรก
- ปรับ **ขนาดภาพ (%)** ได้ 10–200% พร้อมตัวอย่างก่อนบันทึก: 100% ครอบเต็มจอ ต่ำกว่า 100% ย่อจากกึ่งกลางและเติมพื้นที่ว่างด้วยสีดำ มากกว่า 100% ขยายและตัดส่วนเกินขอบจอ โดยรักษาสัดส่วนภาพ
- ภาพที่นำเข้าใหม่จะเก็บไว้เต็มภาพเพื่อย่อ/ขยายภายหลัง หากภาพที่บันทึกด้วยเวอร์ชันเก่าถูกครอบไปแล้ว ให้เลือกนำเข้าจากไฟล์ต้นฉบับใหม่เพื่อคืนส่วนที่ถูกตัด
- ตั้ง **ความเข้มภาพ (%)** ได้ 0–100%: 0% เป็นสีดำ, 100% ใช้ความสว่างเดิม ค่าเริ่มต้น 15% แสดงผลในภาพตัวอย่างทันที ความเข้มนี้แยกจากระดับความทึบของ overlay
- ตั้ง **เวลาภาพจาง (วินาที)** ได้ 0–60 วินาที ค่าเริ่มต้น 5 วินาที หลังหยุดเลื่อน 3 วินาที overlay และภาพจะค่อย ๆ หายตามเวลาที่ตั้ง โดยใช้เวลาจริง ไม่ขึ้นกับความถี่การอัปเดต 0 วินาทีหมายถึงหายทันทีหลังช่วงรอ เมื่อเลื่อนใหม่จะหยุดการจาง
- ปุ่ม **นำภาพออก** แล้วกดบันทึก จะกลับไปใช้พื้นหลังดำ ปุ่ม **ยกเลิก** จะไม่บันทึกค่าหรือภาพที่แก้ไข
- คลิกขวาที่สามเหลี่ยมเพื่อพัก/เปิดการหรี่ เปิดหน้าตั้งค่า หรือออกจากแอป สีเทาหมายถึงพัก กด **F12** เพื่อออกได้เช่นเดิม
- พื้นที่หรี่หน้าจอคลิกทะลุได้ มีเฉพาะสามเหลี่ยมที่รับการคลิก

แอปใช้หน้าต่างโปร่งใสคลุมจอหลัก ไม่ได้เปลี่ยนค่าความสว่างของฮาร์ดแวร์ ค่าเปอร์เซ็นต์คือความทึบของ overlay หากใช้ภาพ ความสว่างที่เห็นจะขึ้นอยู่กับภาพด้วย หน้าต่างแบบเต็มจอ exclusive หรือหน้าจอระบบที่มีการป้องกันอาจไม่แสดง overlay

ค่ากับภาพที่บันทึกจะอยู่ในโฟลเดอร์ `data` ข้างไฟล์ EXE (เช่น `dist\data`) ภาพถูกคัดลอกไว้ จึงไม่ต้องเก็บไฟล์ต้นฉบับ หากย้ายแอปไปอีกโฟลเดอร์ ให้ย้าย `data` ไปด้วย และใช้ตำแหน่งที่เขียนไฟล์ได้

## สร้างไฟล์ EXE ใหม่

โครงสร้างโปรเจกต์:

- `dist/Loomly.exe` — แอพพร้อมใช้งาน ใช้คู่กับ `dist/data` เพื่อเก็บค่าตั้งค่าและภาพ
- `src/` — ซอร์สโค้ดและต้นแบบเคอร์เซอร์ที่จำเป็น
- `tests/` — ชุดทดสอบพฤติกรรมและหน้าต่างบน Windows
- `Loomly.spec`, `build.ps1`, `requirements.txt` — ไฟล์สำหรับ build
- `.venv/` — Python และ dependencies สำหรับ build และทดสอบ ไม่ต้องนำไปแจกพร้อม EXE

การ build ใช้ `Loomly.spec` เป็นค่ากลาง และลบโฟลเดอร์ `build` ชั่วคราวเมื่อสำเร็จ

ติดตั้ง Python พร้อม Tkinter แล้วรัน:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

ค่าเวลาและขนาดสามเหลี่ยมแก้ได้ที่ส่วนบนของ `src/loomly.py` ส่วนค่าการหรี่ตั้งผ่านหน้าตั้งค่าได้

`MAX_DIM = 0.95` กำหนดเพดานความทึบสูงสุด 95% ส่วน `INDICATOR_SIZE = 50` กำหนดขนาดสามเหลี่ยม

ทดสอบโค้ด:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests\verify_windows.py
```
